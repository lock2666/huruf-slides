# رِحْلَةُ الحُرُوفِ الهِجَائِيَّةِ 🎉

شرائح HTML تفاعلية لتعليم الحروف الهجائية من الألف إلى الياء للصف الأول الابتدائي (المنهج السعودي) — إعداد الطالب عبد الملك رامي الطلحي بإشراف الأستاذ محمد الباجوري.

## العرض المباشر

https://lock2666.github.io/huruf-slides/

## الميزات
- ١٤٤ شريحة تفاعلية تغطي الحروف الـ٢٨ كاملة
- بطاقة الحرف ومواضعه في الكلمة والحركات وكلمات وصور
- أنشطة تفاعلية تتولد جديدة كل مرة + لعبة مراجعة وشهادة تفوق
- دفتر أناشيد (٣٣ نشيدًا) مع الترديد الجماعي المتزامن
- 🎙️ صوت بشري حقيقي: يدعم ElevenLabs وMicrosoft Azure (الصوت السعودي حامد) وGoogle Cloud — أو صوت Edge الطبيعي المجاني دون أي مفتاح، مع تراجع تلقائي لصوت الجهاز
- تعمل دون إنترنت (بأقل ميزات) ويفضل الاتصال
